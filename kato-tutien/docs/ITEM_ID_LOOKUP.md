# Tra cứu ID vật phẩm

- `.vatpham` hoặc `.vp`: mở GUI chọn danh mục và vật phẩm để xem ID chính xác.
- `.vatpham <tên hoặc ID>`: tìm vật phẩm; hỗ trợ tìm tên tiếng Việt không dấu.
- Trong Quản trị → Kho Mật Lệnh, nút **Tra ID vật phẩm** mở cùng GUI tra cứu.
- Khi tạo Mật Lệnh, nhập ID trong dấu backtick. Hệ thống xác thực ID và số lượng trước khi lưu để tránh mã thưởng lỗi.

Ví dụ: `.vatpham tu khi dan` sẽ tìm **Tụ Khí Đan** với ID `tu_khi_dan`.
