# Nhạc YouTube

## Lệnh
- `.join` — bot vào kênh thoại của bạn
- `.play <link|tên>` — phát / xếp hàng (YouTube)
- `.skip` — bỏ qua bài hiện tại
- `.stop` — dừng và xóa hàng chờ
- `.queue` — xem hàng chờ
- `.leave` — rời kênh

## Host
Cần **FFmpeg** trên máy chạy bot (Railway: `nixpacks.toml` đã khai báo `ffmpeg`).
Package Python: `yt-dlp` trong `requirements.txt`.
